Agent workflows / Personal project

LangGraph Research Assistant

Parallel analyst interviews, web-grounded retrieval, and human approval inside a stateful research workflow.

Python · LangGraph · LangChain · Tavily · Pydantic

The problem

Research involves multiple perspectives, source gathering, repeated interviews, and synthesizing findings into a coherent report.

System architecture

I built an assistant that generates analyst personas, runs parallel interview workflows, and combines the research into Markdown reports. Tavily supports web-grounded retrieval, with human approval built into the graph.

Implementation

  • Organized the workflow into reusable LangGraph nodes and shared state.
  • Used Pydantic models to structure data passed between workflow steps.
  • Kept human approval in the research flow rather than making all decisions autonomous.

Technical challenges

Parallel work needs structured state and a synthesis step; simply running multiple prompts is not enough to produce a coherent report.

Decisions & trade-offs

Parallel interviews can explore multiple perspectives, while human approval adds a deliberate checkpoint. Runtime comparisons, source-quality evaluation, and failure-recovery behavior have not been published.

Evaluation & outcomes

Built a stateful, human-in-the-loop research workflow that produces structured reports. No research-quality score or speedup is claimed.
